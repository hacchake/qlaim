# QLAIM
Qix風の陣取りアーケードゲーム。`index.html` をブラウザで開くだけで遊べます。

## 操作
- 矢印 / WASD / 画面をなぞる / ゲームパッド: 移動
- 空き地へ進むとそのまま線を引く(ゆっくり・×2点)。Z / スペースを押している間だけ速く引く(×1点)
- X を押す間: カメラが引いて立体の全体が見える
- P: ポーズ(つづける / はじめから / OPTIONS / あそびかた / タイトルへ)、H: あそびかた、M: 消音、C: スクリーンショット
- ゲームオーバー画面: S = 結果をシェア、R = すぐもう一度

## 遊びかた
- 線で囲んで陣地を広げ、目標の占領率でクリア。続けて囲むとコンボ、ヌメリンが線をかすめるとニアミスボーナス
- アイテムは線で囲むと手に入る: S=敵がゆっくり ◆=1回ミスを防ぐ ★=得点2倍 ♥=1UP ✦=バチッコ一掃 ≋=虹色インク ✺=インクがはじける ◐=ローラーの色が変わる
- INK テーマでは線を閉じるたびにインクの色が変わる(ローラーの色 = 次に塗る色)。★の間は金、≋の間は虹色の帯でレインボーアートに
- 球(SPHERE)は色塗りではなく、囲むと地球の地図がだんだんあらわれる(スタートは日本)。地図データは Natural Earth(パブリックドメイン)
- 陣地のあいだの線は、となりの陣地の色がにじんで縫い合わさる
- 塗る音は6種類(もとの音・アルペジオ・無限音階・ハープ・鐘・スタブ)。OPTIONS「塗る音」で選べる。線を描く音は無限音階で、伸ばすほど終わりなく上がり続ける
- 塗った陣地には、そのときの状況で模様がつく: ふつう=グラデーション / 大きく取る=波紋 / じっくり描く=うずまき / SLOW中=波 / コンボ=ストライプ・チェック / STAR中=金の水玉
- OPTIONS「インク」で MIX(いろいろ)・RAINBOW(いつも虹)・好きな1色を選べる
- AREA 3 から ヌメリン2体(分断で即クリア)、AREA 4 から オイカケ(線を追ってくる。囲めば倒せる)
- 5エリアごとに BONUS AREA(40秒で好きなだけ囲む)、AREA 6 から ヌメリンがときどき突進(白く光って予告)
- ゲームオーバー後10秒はコンティニューできる(スコアは0から。ハイスコアは残る)
- TOURの全22面を制覇するとエンディング

## buddy たち(18種)
Clawd の仲間が総出演。迷子の味方(アヒル・ウーパールーパー・カメ・カピバラ・フクロウ・ロボ・ブロブ)は囲んで助けるとごほうび。
陣地をかじるカタツムリ・キノコ、墨で穴をあけるタコ、アイテム泥棒のガチョウ、通せんぼのネコ・デブネコ、
線に触れるとミスのサボテン・ウサギ・ペンギン・ユーレイ・ドラゴン。タイトルで B = buddy図鑑
みんな名前・レア度・性格・ステータスを持っていて、ときどきしゃべる(カメのワーブルは急がないのに、いつも正しい)。
ステータスは動きにも出る(のんびり屋はゆっくり、CHAOS が高いといたずらが多い)。まれに色違いも。
図鑑で選んで Z を押すと、ステータスつきのカードが見られる

Clawd も場面に合わせてしゃべる。ときどきレアなセリフや、季節・曜日・時間に合わせた時事ネタも
