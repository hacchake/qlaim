# QLAIM
Qix風の陣取りアーケードゲーム。`index.html` をブラウザで開くだけで遊べます。

## 操作
- 矢印 / WASD / 画面をなぞる / ゲームパッド: 移動
- 空き地へ進むとそのまま線を引く(ゆっくり・×2点)。Z / スペースを押している間だけ速く引く(×1点)
- P: ポーズ(つづける / はじめから / タイトルへ)、M: 消音、C: スクリーンショット

## 遊びかた
- 線で囲んで陣地を広げ、目標の占領率でクリア。続けて囲むとコンボ
- アイテムは線で囲むと手に入る: S=敵がゆっくり ◆=1回ミスを防ぐ ★=得点2倍 ♥=1UP
- AREA 3 から QIX 2体(分断で即クリア)、AREA 4 から SEEKER(線を追ってくる。囲めば倒せる)
- 5エリアごとに BONUS AREA(40秒で好きなだけ囲む)
- ゲームオーバー後10秒はコンティニューできる
