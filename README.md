# QLAIM
Qix風の陣取りアーケードゲーム。`index.html` をブラウザで開くだけで遊べます。

操作: 矢印/WASDで移動。空き地へ進むとそのまま線を引く(ゆっくり・×2点)。
Z/スペースを押している間だけ速く引く(×1点)。P=ポーズ、M=ミュート

タイトル画面で ←→ を押すと盤面を選べます(TOURは全部を順番に)。
平面・立方体・球・正四/八/12/20面体・切頂四/六/20面体・立方八面体・20・12面体・
星型八面体・小星型12面体・大星型12面体・ドーナツ・クラインの壺。

アイテム(S=敵がゆっくり ◆=1回ミスを防ぐ ★=得点2倍 ♥=1UP)は線で囲むと手に入ります。
続けて囲むとコンボ。画面をなぞっても操作できます。

OPTIONSでBGM(AUTO/クラシック/宇宙/チップチューン/ドローン/アンビエント/IDM)やテーマを選べます。
